**Confronto Elemental — Edição Definitiva** é um jogo de cartas estratégico para navegador desenvolvido com tecnologias web nativas (**HTML5, CSS3 e JavaScript**), publicado automaticamente via **GitHub Actions & GitHub Pages**.

👉 Acesse diretamente pelo GitHub Pages: **[https://mizaelsouto.github.io/jogo4mz.github.io/](https://mizaelsouto.github.io/jogo4mz.github.io/)**

---

## ✨ Mecânicas e Recursos do Jogo

- ☀️🌙🌪️👻 **Sistema de 4 Elementos:** Cartas regidas pelas forças elementais **Sol (`Sun`)**, **Lua (`Moon`)**, **Vento (`Wind`)** e **Espírito (`Spirit`)**, cada uma com sinergias e vantagens táticas.
- 🥇🥈🥉 **Raridades e Níveis:** Cartas classificadas em categorias **Ouro (`Gold`)**, **Prata (`Silver`)** e **Bronze (`Bronze`)**.
- 🃏 **Construtor de Deck (*Deck Builder*):** Interface dedicada para seleção e customização estratégica do baralho antes das partidas.
- 📖 **Guia de Regras Integrado:** Modal interativo com explicação das regras de combate e pontuação.

---

## 📂 Estrutura do Repositório

- `index.html`: Jogo completo (**Confronto Elemental — Edição Definitiva**) com estilos, animações e motor de regras integrados.
